## 📘 Overview

**Finance_AID** is a modern, TypeScript-powered web application designed to provide **financial assistance tools**, **analytics**, and **planning insights**.  
Built with scalability and clean code in mind, the project aims to deliver an intuitive, data-driven user experience for managing and understanding finances.

## ✨ Features

✅ Clean, modular TypeScript structure  
✅ SCSS-based styling for sleek, responsive UI  
✅ Financial tools and aid calculation modules _(in progress)_  
✅ Modern frontend architecture ready for API integrations  
✅ Open source & community-driven

# 🚀 Getting Started

### 🧩 Prerequisites

Before running the project, make sure you have installed:

- [Node.js](https://nodejs.org/) (v16 or later)
- npm or yarn
- Git

---

### ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/IsmailBj/Finance_AID.git

# Navigate into the project folder
cd Finance_AID

# Install dependencies
npm install
# or
yarn install

```

# Start the development server

🖥️ Run the App

```bash
Front-End
    cd ./Client
    npm start
Back-End
    cd ./Service
    npm start
# or
yarn start
```

Once the app is running, visit 👉 http://localhost:3000 in your browser.
